# Proyectos del CFGS ASIR

Prácticas del ciclo de Administración de Sistemas Informáticos en Red (Liceo La Paz), montadas en máquinas virtuales y documentadas paso a paso. Apuntes completos: [daniroca5.gamer.gd](https://daniroca5.gamer.gd/).

## 2.º curso
- **ASO**: dominio Active Directory en Windows Server 2025 (unidades organizativas, usuarios, perfiles móviles, GPO y permisos NTFS).
- **SRI**: DHCP en Windows y Linux, y DNS con zonas directa e inversa.
- **IAW**: servidor web, FTP, WordPress y Joomla, seguridad del blog y publicación en un alojamiento.
- **ASXBD**: MySQL (copias con `mysqldump`, usuarios y privilegios).
- **SAD y ACP**: fundamentos de seguridad, OpenPGP y certificado electrónico.
